# AndroidEssentialLibraries

👻 Android Essential Libraries - A couple of the Android Libraries to use in your Projects 🛠

![alt-text](https://github.com/prateekcode/AndroidEssentialLibraries/blob/main/image/Th1.1.png "Header Image")

A curated directory of **174 open-source Android libraries**, grouped by what you want to build. Use it to find a well-known library for a UI component, animation, media task or architecture concern without digging through search results.

> **Credit where it's due:** every library listed here is the work of its own authors and maintainers. This repository only collects, describes and organises links to them. Check each project's license before you use it.

`archived` marks a library whose GitHub repository its owner has archived (read-only). It still works as published, but it won't get fixes, so prefer an active alternative for new projects. Link status last checked in November 2026: all links resolved, and 23 point to archived repositories.
